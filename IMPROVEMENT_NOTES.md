# Brand and Search Visibility Improvements

## 1. Clarify the external brand name

Keep the legal company name unchanged, but use a clear, industry-specific name on customer-facing material.

- Avoid using **RV-Clean** or **rvcleans** as a standalone title.
- Prefer **RV-Cleanrooms** or **RV Cleanroom Systems**.
- Use the selected name consistently in the website header and metadata, email signatures, LinkedIn company page, and B2B directory profiles.
- Keep **RV-Cleanroom System Co., Ltd.** wherever the legal company name is required.

The word “cleanroom” gives buyers and search engines a clear industrial meaning. “Clean” by itself is too broad and may be confused with cleaning services or recreational vehicles.

## 2. Add B2B organization schema

Add JSON-LD structured data to the home page using:

- `"@context": "https://schema.org"`
- `"@type": "Organization"`
- `name`, `alternateName`, `legalName`, `url`, `logo`, `description`, `address`, `telephone`, `email`, `sameAs`, and `contactPoint`
- `naics` and/or `isicV4` once the company’s correct registered industrial classification has been confirmed

Use `LocalBusiness` only when describing a specific customer-facing physical location and include the applicable local-business fields. Do not use `http://schema.org` as an industry value; it is the vocabulary context. Industry meaning should come from the organization description, relevant properties, classification codes, and the visible page content.

Validate the markup with Google’s Rich Results Test and the Schema Markup Validator before release. Structured data helps search engines understand and disambiguate the company, but it does not guarantee a particular ranking or search-result feature.

## 3. Build industrial semantic authority

- Use a descriptive home-page title such as **RV Cleanroom Systems | Turnkey Modular Cleanrooms & HVAC Engineering**.
- Keep the primary headings and copy focused on cleanroom design, manufacturing, installation, validation, and HVAC engineering.
- Create substantial landing pages for topics such as **ISO Class 5 Cleanrooms**, **GMP-Compliant Cleanrooms**, **Semiconductor Cleanrooms**, and **Laminar Flow Hoods**.
- Give each landing page original technical content, project evidence, specifications, internal links, and a clear inquiry action.
- Use `RV Cleanroom Systems`, `cleanroom manufacturer`, and related industrial phrases naturally. Avoid repetitive keyword stuffing.

“Negative keywords” is mainly a paid-search concept. For organic search, the useful action is to build consistent industrial context and topical coverage.

## 4. Strengthen the B2B digital footprint

- Claim and complete profiles on relevant manufacturing platforms such as Thomasnet, Alibaba, Global Sources, and Made-in-China.
- Use **RV-Cleanroom System Co., Ltd.** consistently on formal directory profiles.
- Keep the address, telephone number, website URL, description, and logo consistent across profiles.
- Seek links and mentions from customers, suppliers, engineering partners, trade publications, and industry associations.
- When editorially appropriate, use descriptive anchor text such as **RV Cleanroom Systems** or **cleanroom manufacturer RV** instead of the ambiguous term **RV** alone.
- Prioritize relevant, reputable placements over a high volume of low-quality directory links.

## Suggested implementation order

1. Select one external brand presentation and update the website’s visible name and metadata.
2. Add and validate Organization JSON-LD.
3. Audit titles, descriptions, headings, and internal links across existing pages.
4. Publish the four priority industrial landing pages.
5. Standardize directory profiles and begin relevant partner outreach.
6. Monitor branded queries, non-branded industrial queries, impressions, and qualified inquiries in Google Search Console.
